# Build instructions for AMO source-code review

Mozilla AMO requires that any extension built from source (TypeScript counts) include build instructions reviewers can follow to reproduce the uploaded XPI. This document maps the uploaded zip back to the source tree.

## Environment

- Node.js v20 or newer (developed against v24).
- npm v9 or newer (ships with Node).
- A POSIX `zip` executable (used by `scripts/package.mjs`). On macOS and Linux this is preinstalled; on Windows use WSL or a Git for Windows shell.

## Reproducing the uploaded XPI

```bash
# 1. Install dependencies (only `pngjs`, `typescript`, `@types/chrome`).
npm install

# 2. Build for Firefox with the production backend URL.
BACKEND_URL=https://pub.cl.uzh.ch/projects/einfach-lesen npm run package:firefox

# 3. The output is releases/einfachlesen-firefox-v<version>.zip.
#    Rename to .xpi if uploading directly; AMO accepts either extension.
```

## Source-to-output mapping

| In the uploaded zip | Source |
|---|---|
| `manifest.json` | `manifest.firefox.json` (with `__BACKEND_URL_HOST__` substituted by `scripts/build.mjs`) |
| `dist/background.js` | `background.ts` (compiled by `tsc`) |
| `dist/content.js` | `content.ts` (compiled by `tsc`) |
| `dist/popup.js` | `popup.ts` (compiled by `tsc`) |
| `dist/src/config.js` | `src/config.ts` (the `BACKEND_URL` literal is rewritten by `scripts/build.mjs` to match the env var) |
| `popup.html` | `popup.html` (copied verbatim) |
| `style.css` | `style.css` (copied verbatim) |
| `icons/*.png` | `icons/icon-{16,48,128}.png` (copied verbatim; `icons/store-128.png` is for the AMO/CWS listing form, not bundled in the extension; generated by `scripts/make-icons.mjs`) |

## What the build script does

`scripts/build.mjs firefox`:

1. Cleans `build/firefox/`.
2. Reads `manifest.firefox.json` and replaces the literal string `__BACKEND_URL_HOST__` in `host_permissions` with `<BACKEND_URL>/*`.
3. Runs `tsc --outDir build/firefox/dist`.
4. Rewrites `export const BACKEND_URL = "..."` in `build/firefox/dist/src/config.js` to match the env var.
5. Copies `popup.html`, `style.css`, and `icons/icon-{16,48,128}.png` into `build/firefox/`.

`scripts/package.mjs firefox`:

1. Reads the version from the staged `build/firefox/manifest.json`.
2. Runs `zip -r releases/einfachlesen-firefox-v<version>.zip .` from inside `build/firefox/`.

## Known maintenance points

- The privacy-policy URL in `popup.html` (`<a href="...">Datenschutz</a>`), in `store-assets/description-en.md`, and in `store-assets/description-de.md` is a GitHub Pages URL on the same repo. If the privacy policy is moved to a separate repo, all three files must be updated and a new build produced.
- The backend URL is **never** committed to the source tree. The committed `src/config.ts` always defaults to `http://localhost:8000`. Production values are injected by the build script via the `BACKEND_URL` env var.

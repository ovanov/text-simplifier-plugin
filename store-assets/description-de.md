# EinfachLesen — vereinfachte Nachrichten für Deutschlernende

EinfachLesen ist eine Forschungserweiterung der Universität Zürich, die deutschsprachige Nachrichtenartikel auf Schweizer Nachrichtenseiten (SRF, 20 Minuten) für L2-Lernende vereinfacht.

## Funktionsweise

1. Öffne einen Artikel auf einer unterstützten Seite (aktuell SRF oder 20 Minuten).
2. Jeder Absatz erhält einen kleinen Button "✨ Text vereinfachen".
3. Beim Klick wird der Absatztext an das Studien-Backend gesendet, das eine an dein angegebenes CEFR-Niveau (A1–B2) angepasste vereinfachte Version zurückgibt.
4. Die vereinfachte Version erscheint direkt unterhalb des Originalabsatzes. Mit "Nochmals vereinfachen" lässt sich eine weiter vereinfachte Variante anfordern.

## Teilnahme und Berechtigungen

Diese Erweiterung ist ausschliesslich für Teilnehmer:innen der Studie gedacht. Eine User Id (per E-Mail erhalten) wird zum Anmelden benötigt.

Berechtigungen:
- **storage** — speichert dein Authentifizierungs-Token zwischen den Sitzungen.
- Zugriff auf **srf.ch** und **20min.ch** — für das Einfügen des Vereinfachungs-Buttons in Artikelabsätze.
- Zugriff auf das Studien-Backend — für das Senden des Absatztextes und das Empfangen der vereinfachten Version.

Die User Id dient ausschliesslich der Zuordnung zu deiner Studienanmeldung — es werden keine personenbezogenen Daten mit ihr verknüpft. Es werden keine Analyse-, Werbe- oder Tracking-Dienste eingesetzt.
